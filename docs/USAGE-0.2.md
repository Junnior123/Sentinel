# Watchblock 0.2 사용·운영 범위

## 같은 컴퓨터에서 확인

1. 로컬 개발 서버를 실행하고 `http://localhost:8787/dev/login`으로 접속합니다.
2. `검사 만들기`에서 **전체 파일·드라이브 검사**, **하드웨어 변경 흔적**을 원하는 범위로 선택합니다. 새 검사는 두 옵션이 기본 선택됩니다.
3. 초대 링크를 0.2 앱에 붙여넣습니다. 플레이어가 `전체 드라이브` 또는 폴더를 선택하고 공유 내용을 확인·동의하면 시작됩니다. 전체 드라이브 선택만으로 검사하지는 않습니다.
4. 결과를 검토한 뒤 제출합니다. 10MB를 넘는 결과는 일부만 전송됩니다. 탐지 근거·실행 흔적·누락·탐지 파일을 우선 전송하며 **보고서 저장**으로 전체 로컬 결과를 보관할 수 있습니다.

앱은 기본 최대화로 열립니다. 검사 위치와 전송 내용을 나란히 확인하고, 결과 화면에서 실제 검사 수·치트 일치·검토 필요·누락 수를 확인합니다.

## 전체 파일 검사란

선택한 로컬 드라이브/폴더를 재귀 열거해 **확장자에 관계없이 파일 목록·크기·SHA-256**을 기록합니다. EXE·DLL·SYS와 ZIP/JAR는 내용의 파일 형식을 판별하므로 확장자를 바꿔도 지원 형식으로 확인할 수 있습니다. 지원하는 모드·스크립트는 추가 정적 검사를 합니다. 문서·사진 등 미지원 형식은 해시 검사만 하며, 문서의 단어를 매크로 패턴으로 해석하지 않습니다. 개인 파일 이름도 공유 범위에 포함된다는 점을 동의 화면에 표시합니다. 파일 내용·원본은 전송하지 않습니다.

- 파일당 256MB, 최대 250,000개 파일·100,000개 폴더. 큰 파일·권한 부족·손상·심볼릭 링크·클라우드 전용 파일은 검사 제한을 표시합니다. 클라우드 파일을 자동 다운로드하지 않습니다.
- 드라이브 전체는 수십 분 이상 걸릴 수 있습니다. 현재 수량을 표시하고 취소할 수 있습니다. 지원하지 않는 형식의 의미까지 분석하거나 모든 핵을 탐지한다는 뜻은 아닙니다.
- 관리자 권한 옵션은 실행 흔적 보조 수집에 적용됩니다. 보호된 파일까지 읽으려면 **플레이어가 앱 자체를 관리자 권한으로 실행**해야 합니다. 그래도 Windows가 막는 항목은 남을 수 있습니다.
- 프리캠·미니맵·엑스레이는 이 운영 정책에서 치트로 분류합니다. 다른 서버에서 허용되는 유틸리티를 악성코드라고 주장하는 분류가 아닙니다.

## 확인한 모드·팩

정확한 버전·해시는 `samples/manifest.json`, 규칙은 `rules/catalog.json`에 고정됩니다. 자동 최신판 신뢰·온라인 AI 판정은 하지 않습니다.

| 분류 | 확인한 공식 표본 | 다른 형태 |
|---|---|---|
| 엑스레이 모드 | [Advanced XRay](https://github.com/AdvancedXRay/XRay-Mod) Fabric·NeoForge 26.2.0.1 | 클래스 조합은 검토 필요 |
| 엑스레이 팩 | [Spectator Xray](https://modrinth.com/resourcepack/x-ray/version/uLQMkfCi) 1.2.1 | 내부 모델 3개 해시로 ZIP 재압축·압축 해제 폴더도 확인 |
| 프리캠 | [Freecam](https://modrinth.com/mod/freecam/version/Cg10zLnR) 1.3.0+mc1.21.1 | 확인한 클래스 조합은 검토 필요 |
| 미니맵 | [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap/version/ZD6hK4GV) Fabric 1.21.1-26.5.0, [JourneyMap](https://modrinth.com/mod/journeymap/version/qmuZAgdA) 1.21.1-6.0.8 | 확인한 클래스 조합은 검토 필요 |

기존 Meteor·오토클리커·매크로 규칙도 유지합니다. 위 이름과 비슷하다는 이유만으로 탐지하지 않습니다. Spectator Xray는 관전자 모드용이며 파일 발견이 생존 서버에서의 사용 증거는 아닙니다. 정상 방어용 Anti Xray 팩은 별도의 음성 표본으로 확인합니다. 아직 모든 버전·모든 종류의 미니맵/프리캠/엑스레이를 포괄하지 않습니다.

## 하드웨어·스푸핑 관련 확인

- [SMBIOS 펌웨어 정보](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-getsystemfirmwaretable)와 Windows 설치 식별값을 로컬 SHA-256 기준과 비교합니다. 기준 파일은 `%LOCALAPPDATA%/Watchblock/hardware-baseline.json`입니다. 첫 실행은 과거 비교를 할 수 없습니다. 원본 값과 기준 해시는 서버에 전송하지 않습니다.
- 네트워크 드라이버의 [NetworkAddress 재정의 설정](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/ndis/nf-ndis-ndisreadnetworkaddress)을 확인합니다. 주소 원문은 보고하지 않습니다. 실제 적용 여부는 확인하지 않습니다.
- [코드 무결성 정책](https://learn.microsoft.com/en-us/windows/win32/api/winternl/nf-winternl-ntquerysysteminformation)의 테스트 서명 허용 상태를 확인합니다.

이 항목들은 **검토 필요**입니다. 부품 교체·BIOS 업데이트·Windows 재설치·관리용 네트워크 설정·드라이버 개발도 원인이 됩니다. 로컬 기준 삭제·변조, 기록 전 스푸핑, 커널에서 값을 숨기는 도구는 확인할 수 없습니다. 스푸퍼를 모두 찾아내거나 해당 시도를 확정하는 기능은 아닙니다.

## 직접 해야 하는 작업

외부 플레이어에게 쓰려면 [Cloudflare 설치 안내](DEPLOY.md)에 따라 **Cloudflare/GitHub 계정 로그인, D1 DB 생성, GitHub OAuth App 생성·비밀키 등록, 실제 서비스 주소 설정과 배포**가 필요합니다. 계정 자격 증명과 서버 주소가 아직 제공되지 않아 공개 서버는 배포하지 않았습니다. localhost는 다른 사람의 PC에서 연결되지 않습니다.

배포 후 운영자는 초대 화면에서 서버 설정 파일을 받아 `Watchblock.exe` 옆에 넣어 앱 ZIP과 함께 배포하면 됩니다. 플레이어는 코드만 입력할 수 있습니다. 0.1 앱은 확장 검사를 지원하지 않으므로 0.2 앱과 웹을 함께 업데이트하세요. 이전 앱은 확장 검사 코드를 소비하지 않고 업데이트 안내를 받습니다.

정식 운영 전 Windows 11 실기기, 실제 OAuth 로그인·운영자 권한 분리, 대규모 디스크·네트워크 단절, 관리자 보조 수집을 확인해야 합니다. 현재 배포물은 개발 검증판이며 미검증 범위는 `VALIDATION.md`에 기록합니다.
