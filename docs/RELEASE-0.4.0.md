# Sentinel 0.4.0

## 앱 업데이트

1. 실행 중인 Sentinel과 검사를 종료합니다.
2. `Sentinel-0.4.0-Setup-x64.exe`를 실행합니다. 이전 서버 설정은 보존됩니다.
3. 웹을 새로고침한 뒤 새 초대를 발급합니다. 이미 제출한 보고서는 새 검사로 바뀌지 않습니다.

상단 단계 표시, 넓어진 결과 표, 새 연결·진행 화면을 적용했습니다. 버튼 반응·단계 전환·진행 막대에 애니메이션을 넣었으며 Windows 애니메이션 끄기 설정을 따릅니다.

## 빠른 검사

**게임 데이터·드라이버·임시 저장소 제외**가 기본 선택됩니다. 앱의 **제외 위치 보기**에서 확인하고 해제하면 다시 포함할 수 있습니다. 폴더 자체를 열거하지 않아 게임 데이터와 임시 파일의 해시 계산을 줄입니다. 나머지 파일은 기존 내용 검사·해시·손상 파일 검사를 유지합니다. 제외한 위치는 보고서의 검사 누락에 표시됩니다.

기본 설치 경로를 기준으로 하므로 임의 위치의 게임까지 모두 제외하지는 않습니다. Downloads에 `steam.jar`, `temp`라는 이름만 붙여도 검사를 피할 수 있는 방식은 아닙니다.

## 사용자가 삭제한 파일

검사 범위에서 **휴지통·최근 삭제 기록 확인**을 선택합니다. 운영자 웹에서 실행 흔적 검사를 켠 초대여야 합니다. 비운 휴지통의 NTFS 기록을 확인하려면 **실행 흔적 확인에 관리자 권한 사용**도 선택하고 Windows 권한 창을 승인하세요.

| 결과 | 실제 확인한 내용 |
| --- | --- |
| 휴지통 | 현재 사용자 `$I` 메타데이터의 원래 위치·휴지통 이동 시각 |
| 휴지통 내용 검사 | `$R` 파일 내용이 남아 있으면 기존 규칙으로 해시·내용 검사. 파일 목록에 `휴지통/` 표시 |
| 삭제 저널 | NTFS의 삭제 기록. 이전 이름변경 기록이 함께 남아 있으면 같은 파일 ID로 원래 이름 연결 |
| 삭제된 파일 이름 검토 | Xray 등 규칙에 등록된 이름 단서만 일치. 내용이 없으므로 치트 확정 판정하지 않음 |

**실행·삭제 흔적**에서 행을 선택하면 시각·경로·근거를 확인합니다. 휴지통 이동 시각과 완전 삭제 시각은 구분합니다. 삭제한 사람이 누구인지, 그 파일을 게임에서 사용했는지는 이 기록만으로 확정할 수 없습니다.

휴지통 메타데이터는 최대 500건/작업 간 10초 예산, 저널은 잔존 마지막 32MiB의 최근 7일, 최대 500개 결과/20,000개 기록/작업 간 8초 예산으로 제한합니다. OS 읽기 호출 하나에 걸리는 시간은 별도입니다. 개인 문서 삭제 이력은 수집하지 않고 모드·압축·실행 파일·지원 스크립트 확장자만 봅니다. 내용이 없는 `sodium.jar`가 사실 치트였는지는 판별할 수 없습니다. 로그가 덮어써졌거나 부모 경로를 찾을 수 없으면 누락으로 표시합니다. 저널을 생성·초기화·삭제하지 않고 파일을 복구하거나 실행하지 않습니다.

이는 Defender 처리 이력이 아닌 사용자 파일의 휴지통·파일 시스템 흔적 검사입니다. 별도 백신 로그는 수집하지 않습니다.

## 상세 공개 보고서

완료 보고서의 **공개 보고서 공유**에서 항목 선택 → 공개 동의 → 링크 만들기를 진행합니다. 상세 항목은 기본 해제되어 있으며 기존 요약 링크는 자동 확장되지 않습니다. 파일명·해시·증거를 공개할 수 있으므로 범위를 확인하세요. 100개씩 조회하며 재발급·철회·보관 만료가 모든 상세 페이지에 적용됩니다.

서버 업데이트: `pnpm exec wrangler d1 migrations apply watchblock --remote`로 **0003**까지 적용하고 웹/API를 함께 배포하세요. 로컬 개발 서버는 재시작하면 자동 적용합니다. 공개 호스팅·GitHub OAuth 설정은 [처음 사용 안내](GETTING_STARTED.md)를 따릅니다.

## 검증의 범위

휴지통 v1/v2, 손상 메타데이터, USN V2 경계 검사·이름 연결·범위 마스킹·취소를 생성 표본으로 검증합니다. 실제 사용자 휴지통을 비우는 테스트는 하지 않습니다. 관리자 권한에서 실제 비운 휴지통 기록이 유지되는지, Windows 11 실기기와 외부 Cloudflare 배포는 운영 전 추가 확인이 필요합니다.
