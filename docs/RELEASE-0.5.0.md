# Sentinel 0.5.0 · 실서버 배포 준비

웹·API는 Cloudflare Workers + D1, Windows Setup은 GitHub Releases에 배포하는 구성입니다. 공개 서버 주소는 운영자가 설정합니다. 이번 패키지를 설치했다고 공용 서버가 자동 생성되지는 않습니다.

## 변경 사항

- 질문에 답하면 실서버 설정을 만드는 `pnpm setup:production` 추가. GitHub 사용자명으로 숫자 ID 조회, HTTPS·D1 ID·설치 파일 링크 검증.
- 배포 명령과 Actions가 `wrangler.production.json`을 사용. localhost·미입력 DB·파일에 넣은 OAuth 자격 증명을 배포 전에 차단.
- 서비스 상태 API가 DB 연결·로그인 준비 여부를 확인. 잘못된 서비스 주소·미설정 서버의 검사 접수 차단.
- 웹 로그인 화면과 플레이어 초대에 Windows Setup 다운로드 연결. 미설정·접속 실패·한도 오류를 별도 안내.
- 같은 탭에서 초대·공개 보고서 링크로 이동하는 화면 전환 수정.
- 보안 헤더, 정적 화면 CSP, 검색 엔진 색인 제외, 비활성 탭 조회 중지와 30초 간격 목록 갱신.
- 앱 연결 전 서버 버전·준비 상태 확인. 안전하게 반복 가능한 업로드·완료 요청은 일시 오류 시 최대 두 번 재시도. 코드를 사용하는 요청은 자동 재시도하지 않음.
- 검사 완료 알림이 실패해도 보고서 유지. 제출 완료 응답을 잃은 경우에도 같은 보고서를 다시 제출 가능. 다른 내용으로 덮어쓰기는 계속 차단.
- 외부 URL로 인증 토큰 전송 차단, 리디렉션 거부, 응답 1MiB 제한, 취소 유지.
- 13개 무료 호스팅 비교와 계정 가입부터 첫 공개 검사까지 한국어 안내 제공.

## 검증 범위

- .NET 회귀 검증 118개: 기존 검사 표본·정상 파일·삭제 기록 파서·네트워크 오류와 재시도.
- API 17개와 배포 설정 2개 테스트 통과.
- WPF 앱: 초대 → 동의 → 공식 출처 표본 11개 정적 검사 → 서버 보고서 제출 통과.
- 브라우저: 실제 초대 발급·파일 다운로드·로그인·상세 보고서·공유/철회 통과. 900px 보고서 및 390px 초대 화면 확인. 실서버 미설정·HTML 오류 응답·다운로드 버튼은 모의 API로 확인.
- 프로덕션 실행 의존성 감사: 확인 시 알려진 취약점 없음. 이는 전체 소스 보안 감사나 모든 취약점 부재의 보증은 아님.
- Cloudflare Wrangler dry-run 번들 생성 확인. 실제 계정 배포와 무료 CPU 한도 부하 시험은 아님.

실제 Cloudflare 계정·OAuth·GitHub Releases 게시, 다른 PC 접속, Windows 11 설치/실행, 관리자 권한의 실제 휴지통 비우기 이력 검증은 남아 있습니다. 개발 PC의 기존 Sentinel 설치는 자동으로 덮어쓰지 않습니다. Setup은 코드 서명되지 않았습니다.
